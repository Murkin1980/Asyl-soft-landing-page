# Исправление ошибок аудита (bag fix, lightbox counter, SEO, названия проектов, чат)

Исправлены баги и недочеты, выявленные при аудите сайта.

### 1. 🐛 Баг фильтрации в лайтбоксе (фикс `getAllItems()`)
- `getAllItems()` теперь выбирает `.portfolio-item` только внутри видимых `.portfolio-category-group:not(.hidden)`, а не по классу `.hidden` на самом элементе
- При фильтрации кнопки "Кухни" и нажатии "Вперед" в лайтбоксе больше не показываются скрытые категории

### 2. 🖼️ Счётчик в лайтбоксе
- Добавлен `<div class="lightbox-counter" id="lightboxCounter">` в HTML-структуру лайтбокса
- `openLightbox()` обновляет текст: `"3 из 12"`

### 3. 💬 Формат сообщения WhatsApp из чата
- В шаблоне `handleChatPhoneSubmit()` поле "Текущая стадия" переименовано в "Стадия проекта"
- В `handleChatTextSubmit()` текст кастомного вопроса теперь передаётся в поле `chatStepState.stage`, а не вшит в строку "Вопрос в чате: ..."

### 4. 🔍 SEO-заголовок
- `<title>` изменён с `"TUBA — Корпусная и встроенная мебель на заказ в Алматы"` на `"TUBA | Мебель на заказ в Алматы: Кухни, шкафы, гардеробные"`

### 5. 🏷️ Названия проектов
20 проектных групп переименованы из шаблонных "Прихожая 1", "Кухня 3" и т.д. в детальные описания:
- Прихожие: привязка к ЖК Esentai City, мкр. Самал, ул. Жарокова, Бостандыкский р-н
- Кухни: по материалам и типу (эмаль, шпон, остров, барная стойка, минимализм)
- Детские: по функционалу (кровать-чердак, подростковая, письменный стол)
- Шкафы: по типу (встроенный шкаф-купе, гардеробная, раздвижная система)
- Санузлы: по назначению (тумба, встроенный шкаф в ванной)
- ТВ-зона: с описанием стеллажей

### Файлы
- `index.html`: новый title, lightbox counter, 20 проектов переименованы
- `script.js`: fix `getAllItems`, counter update, chat template
